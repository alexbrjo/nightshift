# nightshift

I want to run bigger [LLM experiments and benchmarks](https://github.com/alexbrjo/llm-language-quiz-experiments) without needing to click buttons. That is a tool to do that.


## I want to use this!

This project is in a pre-release state. This means I am pushing straight to main and I do not guarentee the stability of APIs/data formats. If you want to run this you must download the source and build it.  If I do a release on github, this process might change.
