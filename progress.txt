# Nightshift Implementation Progress

## Overview
Desktop-first experimentation platform for evaluating LLM-generated context.

## Tech Stack Decisions
- Framework: Tauri (Rust backend + React frontend) - lightweight, secure, cross-platform desktop
- Backend: Rust with SQLite (sqlx), async runtime (tokio)
- Frontend: React + TypeScript + Tailwind CSS
- State Management: Zustand or TanStack Query
- Code Editor: Monaco Editor (VS Code's editor)
- Pipeline/Workflow: Custom workflow editor (React Flow for production)

## Build & Run
1. Install Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
2. Run setup: `./setup.sh`  
3. Start dev server: `npm run tauri dev`
