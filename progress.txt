## Build Instructions:
```bash
npm install    # Install dependencies
npm run dev    # Start development server with Electron
```

## Architecture Notes:
- Desktop-first: Uses Electron for native desktop features
- Filesystem as source of truth: All content lives in project files
- SQLite store: Persists experiment data and metadata per-project
- OpenAI-compatible inference: Works with any OpenAI-like API provider
- Sandboxed agents: Each analysis runs in isolated scope
